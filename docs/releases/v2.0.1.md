# SxDevOps v2.0.1 版本更新说明

本文记录 `v2.0.1` 的修复内容与升级要求，可用于 GitHub Release。发行源码以 `refs/tags/v2.0.1` 为准。

v2.0.1 是一次以**缺陷修复与安全加固**为主的维护版本，不改变平台主流程与数据模型语义（仅新增一个带默认值的字段）。

## 升级要求

1. 执行数据库迁移（Docker 入口会自动执行）：

   ```bash
   python manage.py migrate
   ```

   本版新增 `multicloud.0004_cloudcredential_verify_ssl`。

2. **vSphere / ESXi TLS 默认改为校验证书。** 新增字段 `verify_ssl`，默认 `true`。使用自签证书的环境需在该云账号上显式关闭校验；若未关闭，连接会因证书不受信任而失败。

3. 以下权限边界收紧，升级前请确认相应角色：
   - 查询时自定义日志数据源连接参数（endpoint/凭据等）需要 `ops.log.datasource.manage`；只有 `ops.log.query` 的账号请改用已保存的日志数据源。
   - 请求级 `grafana_url` 需要 `ops.grafana.manage`。
   - 系统态势历史的 `refresh` / `backfill` 需要 `ops.observability.system_posture.manage`。
   - K8s 集群终端除 `role=admin`、无命名空间限制外，还需要 `allow_exec`。
   - Marketplace 部署到主机需要 `ops.host.manage`；部署到集群需要落在 `K8sUserAccess` 授权范围内。
   - 导入/同步时隐式新建 CI 模型需要 `cmdb.model.manage`。

## 修复内容

### 崩溃与错误行为

- 修复 MCP STDIO 服务器创建/更新时因缺少 `_validate_mcp_stdio_command` 导入而抛 `NameError`。
- 修复 `HostSerializer` 明文返回 SSH 密码；改为只写字段。
- 修复部署日志 `tail`、主机定时任务 `target_host_ids`、Runbook 关联 ID 等非法入参导致的 500。
- 修复 `test_connection` / `refresh_info` 异常路径 SSH 连接泄漏。
- 修复 CMDB `stats` 聚合被排序字段污染 GROUP BY，导致每类计数恒为 1。
- 修复 CMDB 导入格式判定优先级错误：单行 JSON 被当作 CSV 静默导入 0 条。
- 修复同步任务参数错误时永久停留在 `running`。
- 修复 CMDB 授权策略全空时语义相反（列表看不到任何资产、单点却放行）。
- 修复调度任务 `interval` 缺省 0 时被每轮轮询重复执行。
- 修复网络告警 `conflict_rate` 判定恒真使 `critical_rate` 失效。
- 修复屏蔽规则覆盖 `resolved` 导致恢复通知丢失、告警永久 muted。
- 修复 Cron `0/15` 与 `0-7` 解析错误导致下次执行时间算错。
- 修复前端日志多关键词高亮把 `<mark>` 标签自身再次替换，产出畸形 HTML。
- 修复 `WebShell` 页面卸载竞态与 `ResizeObserver` 泄漏。
- 修复发布单、主机页面未拉取资源树导致「系统/环境」下拉为空、无法保存。
- 修复 `eventwall` 内置事件源被停用后在任意一次读取时被静默恢复。
- 修复 `eventwall` 驳回事件被直接丢弃，审计链中断。
- 修复 SQL 工单「审核通过」缺少审计事件。
- 修复 `marketplace/deployer.py` 多处中文被写成 `?` 的编码事故。
- 修复 K8s `pod_exec` 把 `(connect, read)` 元组传给 WebSocket 超时导致真实集群恒失败。

### 安全加固

- K8s Pod exec WebSocket 接入 WebShell 高危命令拦截与审计（此前是唯一未接入的终端通道）。
- kubectl 控制台黑名单补充 `--from-file`/`--from-env-file`/`--patch-file`/`--raw`，并禁止 `kubectl config`。
- 日志查询与 Grafana 查询禁止请求级任意地址覆盖（SSRF）。
- 部署脚本、镜像发布、Nginx/Playbook 路径统一 `shlex.quote`，堵住命令注入。
- WebShell 缓冲区超限不再静默丢弃，改为拦截。
- MCP STDIO 拒绝带路径的可执行文件，避免 `/tmp/x/npx` 绕过白名单；外部 MCP 只读黑名单覆盖更多写操作动词。
- SQL 审计：MongoDB 只读查询拒绝 `$out`/`$merge`/`$function`/`$where`；MySQL 查询改为流式游标并加读超时/最长执行时间；只读查询拒绝 `INTO OUTFILE`/`LOAD_FILE`。
- AIOps 告警按 ID 查询不再回退到全局（跨环境越权）。
- AIOps 知识图谱与 catalog 按 K8s 授权、Docker/任务资源权限收敛，并按用户隔离缓存。
- AIOps `auth_config` 必须是 JSON 对象；Runbook `status` 改为只读，只能经发布/归档动作迁移。
- `confirm_action` 改为单事务状态迁移，异常不再永久卡在 `confirmed`。
- Marketplace `env_config` 禁止换行，序列化器与渲染层双重防护。
- vSphere TLS 默认校验证书。
- 云账号同步不再按 `(name, ci_type)` 归并覆盖同名手工资产；同步异常会把任务置为失败。
- 内置模型清理按名称命中时限定 `is_builtin`，避免误删用户资产。
- 全量同步本批次有失败/冲突时不再推断「源端已删除」，避免误置资产离线。
- 订阅成本按 `end+1 天` 归一计算月数；同一资源多 CI 时只记主 CI，避免重复入账。
- 自动交付增加原子占位与幂等：云侧已建出的实例在重试时只补入库，不再重复建机。
- 关系同步的对端解析按操作者 `manage` 授权范围过滤。
- 事件源创建/更新/删除/签发令牌/启停全部补审计。
- WAF 事件翻页上限 10 页，避免大时间窗打满云 API 配额。

### IDC 上架布线（planning）

- 跨柜拖动不再把目的柜里同型号邻居误当成自己：拖进已占用 U 段会被拒绝，不再出现两台设备叠在同一 U 段。
- 占用计算按段取 U 高度缺省（`switches` 1U / `devices` 2U），2U 设备不再被当成 1U。
- 交换机组 `instances` 在粘贴/填充/单格编辑时统一按分号/逗号拆成数组；复制按分号还原；补齐 `order`（排序轴）列，复制→粘贴往返恒等。
- `/api/models/import` 的项目名增加白名单与 `resolve()` 前缀校验，禁止任意目录写入。
- `/api/compare/stocks` 路径收敛到 `信息港部署上架/` 子树。
