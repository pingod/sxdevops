# SxDevOps v2.0.3 版本更新说明

本文记录 `v2.0.3` 的功能变更与升级要求，可用于 GitHub Release。发行源码以 `refs/tags/v2.0.3` 为准。

逐项改动、迁移清单与真实验证结果见[维护记录](../维护记录.md#2026-11-18--v203--凭据加密与执行链路自愈)。

v2.0.3 的主题是**凭据加密与执行链路自愈**：把散落在各处的明文凭据统一收进平台密钥，并修掉一批“看起来成功、实际可重复执行/可绕过”的执行与鉴权问题。

## 升级要求

1. **必须显式配置并长期保留 `CMDB_PASSWORD_ENCRYPTION_KEY`**（32 字节 urlsafe base64 的 Fernet 密钥）。本版起 SSH 口令、SQL 数据源密码、云厂商 AK/SK、模型 API Key、MCP 鉴权配置都使用这把密钥，缺失时相关功能会直接报“未配置密钥”，而不是退化为明文。

2. 执行数据库迁移（Compose 入口会自动执行）：

   ```bash
   python manage.py migrate
   ```

   本版新增迁移：

   | 迁移 | 说明 |
   | --- | --- |
   | `ops.0064_encrypt_ssh_passwords` | `Host` / `TaskResource` / `DockerHost` / `NginxEnvironment` 的 SSH 口令就地加密 |
   | `sqlaudit.0004_*`（加密数据源口令） | `DataSource.password` 改名 `password_encrypted` 并加密历史值 |
   | `multicloud.0005_encrypt_cloud_credentials` | `access_key_secret` 改名 `access_key_secret_encrypted` 并加密 |
   | `aiops.0031_encrypt_mcp_auth_config` | MCP `auth_config` 改名 `auth_config_encrypted` 并加密 |
   | `sqlaudit.0005_datasource_is_demo` | 演示数据源改为显式 `is_demo` 标记 |
   | `cmdb.0047_cost_record_unique` | 成本记录加 `(ci, month, provider)` 唯一约束（先删历史重复行） |
   | `rbac.0015_websocket_ticket` | WebSocket 一次性短票据 |

   迁移会打印加密条数。若旧库是在迁移之后才导入的明文数据，可补跑：

   ```bash
   python manage.py encrypt_ssh_passwords
   ```

3. 重建应用镜像（依赖改为按 `backend/requirements.lock.txt` 精确安装）。

4. Compose 部署会新增两个服务，必须一起启动：`alert-escalation-scheduler`（告警升级周期扫描）与 `observability-scheduler`（态势快照刷新，替代原先每个 worker 各起一条线程）。应用容器的进程内调度线程已由 `SXDEVOPS_OBSERVABILITY_SCHEDULER=0` 关闭。

5. **`CORS_ALLOW_ALL_ORIGINS` 默认值由 `1` 改为 `0`**。如果确实需要跨域直连 API，请显式设置该变量；同源部署无需改动。

6. 前端与后端必须同版本升级：终端连接改用 `/auth/ws-ticket/` 一次性票据。旧 `?token=` 仍可用一个版本，但会在日志里持续告警。

7. 受管主机的 SSH 主机密钥改为首次记录、之后拒绝变更（TOFU）。请确保容器/节点的 `/app/backend/runtime` 是持久卷；若某台主机密钥确实变更过，从 `runtime/known_hosts` 删除该主机条目后重连即可。临时关闭校验可用 `SXDEVOPS_SSH_STRICT_HOST_KEY=0`（会打印告警，不建议长期开启）。

8. 新增可选环境变量：

   | 变量 | 默认 | 说明 |
   | --- | --- | --- |
   | `EMAIL_TIMEOUT` | `10` | 告警邮件外发超时（秒） |
   | `SXDEVOPS_SSH_KNOWN_HOSTS` | `<BASE_DIR>/runtime/known_hosts` | known_hosts 路径 |
   | `SXDEVOPS_SSH_STRICT_HOST_KEY` | `1` | 关闭后回到 AutoAddPolicy |
   | `SXDEVOPS_OBSERVABILITY_SCHEDULER` | `1` | `0` 时不启动进程内调度线程 |

9. 探针：新增 `GET /healthz`（不查库）。Kubernetes 清单的存活/就绪探针已改为 HTTP 探针，并新增 `sxdevops-runtime` PVC。

## 安全

- 统一密钥工具 `sxdevops/secrets.py`，密文带 `fernet:v1:` 前缀，历史明文仅在读取时兼容，写入即加密。
- CMDB 采集凭据只能来自 `SXDEVOPS_COLLECTOR_<AUTH_REF>_<FIELD>` 前缀的环境变量；`auth_ref` 必须是大写字母/数字/下划线。此前可用 `auth_ref` 读取任意进程环境变量（如 `POSTGRES_PASSWORD`）。
- 任务中心的 kubectl 命令复用控制台同一套参数闸门，`-f` / `--from-file` / `--server` / `--token` / `--insecure-skip-tls-verify` 等全部拦截。
- K8s 集群终端降权失败即关闭连接，不再静默降级成持有集群凭据的 root shell；`RLIMIT_NPROC` 不再限制（它作用于整个 uid，会让 shell 直接 fork 失败）。
- Ansible 口令改由环境变量传入，不再出现在 `ansible` / `ansible-playbook` 的 argv 与 auditd 记录里。
- MCP：stdio 白名单逐 token 校验 `--package`，HTTP 端点拒绝内网/回环/链路本地地址且不跟随重定向；鉴权配置序列化只回显“是否已配置”。
- 模型提供商测试失败的异常文案统一脱敏，不再把含 API Key 的原文写进 `last_test_message`。
- 新增全局用户级限流（`600/min`）、昂贵查询限流（`30/min`）与资产密码查看限流（`10/min`），密码查看失败会写安全事件。

## 执行链路

- SQL 工单执行改为条件更新领取，并发重复提交只有一个能执行，冲突返回 409；长时间停在 `executing` 的工单会被列表入口回收为失败。
- SQL 检查器的“有 WHERE”改为语法级判定：`UPDATE t SET label='nowhere'` 不再被当作带条件；`TRUNCATE` / `DROP` 用首个非注释关键字识别。
- MySQL 查询与 PostgreSQL 对齐：executor 内二次校验 + 只允许单条语句。
- 主机任务计划改为原子摘取 `next_run_at`，多副本轮询不会重复触发；领取后异常会归还到期时间。
- 执行中超时回收阈值改为随批量规模放大（`max(1800, timeout × targets × 2)`），并接入调度循环，避免 worker 崩溃后计划永久卡住。
- 告警写入事务只计算升级级别，网络外发统一移到 `on_commit` 之后；新增告警升级调度器，``15 分钟后升级二线`` 不再依赖有人再推一次告警。
- 告警交互令牌改条件消费，重复点击/重复投递只生效一次。
- CMDB 采集任务原子领取，并回收 2 小时未回写的 `running` 任务。
- AIOps 聊天任务：收尾只写终态、领取决不过重试上限、`running` + 空租约的历史脏数据可自愈；`metadata` 读改写加行锁。

## 前端

- 会话过期时同步清理 Pinia 与本地存储；成本、日志查询历史/收藏、AIOps 会话草稿等缓存全部按用户隔离，登出即清。
- 终端连接改用一次性短票据，长期 Token 不再进入 WS 查询串与访问日志。
- 任务执行确认弹窗改纯文本渲染，避免任务名注入 HTML。
- 数据源地址统一走 `safeHttpUrl` 校验，非法地址给出提示而不是打开。
- 日志/指标/链路查询超时提升到 120 秒。

## 已知限制

- 平台密钥轮换（换 `CMDB_PASSWORD_ENCRYPTION_KEY`）仍需要单独的解密再加密工具，本版未提供；升级时请保持密钥不变。
- WebSocket 旧 `?token=` 兼容只保留一个版本，下个版本删除。
- 浏览器手工检查项（登录态失效跳转、跨账号缓存隔离、弹窗转义）需要在有浏览器会话的环境补充验证。
