# SxDevOps v2.0.2 版本更新说明

本文记录 `v2.0.2` 的功能变更与升级要求，可用于 GitHub Release。发行源码以 `refs/tags/v2.0.2` 为准。

v2.0.2 的主题是**数据中心编辑入口收敛**与**AI 机房建模接入 AIOps**。

## 升级要求

1. 执行数据库迁移（Compose 入口会自动执行）：

   ```bash
   python manage.py migrate
   ```

   本版新增 `aiops.0030_aiopsmodelinvocation_modeling_purpose`，仅扩展模型调用审计的 `purpose` 选项。

2. 重建应用镜像并重建五项应用容器。镜像构建新增 `tools/dc-designer` 阶段，并会把 `tools/dc-viewer` 作为其检视子应用一起放入 `/dc-designer-app/inspect/`。

3. 使用 `AIOps → AI 机房建模` 前，在 `AIOps → 智能体配置 → 模型提供商` 中配置并测试默认模型提供商。未配置时模型代理返回 503，并写入失败审计。

4. 无需新增权限码：`三维机房设计` 沿用 `datacenter.twin.manage`，`AI 机房建模` 沿用 `aiops.chat.view`。

## 数据中心

- `三维机房设计` 改用 CAD 编辑内核，保留项目库、版本历史、乐观锁与原有克隆/版本入口。
- 新增平台桥接：`ready/dirty/save/error` 与 `load/new-room/request-save/saved/cancel/error`；平台负责项目库与版本，编辑器只持有当前画布。
- 平台模式隐藏 CAD 自带的本地文件组与工勘向导，`Ctrl+S` 走平台保存；工具栏保留「独立工作台」用于本地/离线工单。
- 删除重复的「机房 CAD 设计」菜单与页面；`/dc-designer-app/` 静态应用仍由后端托管，供平台编辑器和独立工作台使用。
- DXF/CSV/PNG、16 类构件、合规检查、3D 检视和独立 AI 模式保留。

## AIOps / AI 机房建模

- 新增 `AIOps → AI 机房建模` 页面；设计器默认不加载 AI，只有 AIOps 模式通过 `?ai=1` 打开。
- 新增 `GET /api/aiops/modeling/status/` 与 `POST /api/aiops/modeling/chat/`：
  - 使用 AIOps 默认模型提供商，服务端调用，浏览器不接触模型 Key。
  - 限制消息数 80、字符数 20 万，客户端不能覆盖模型/地址/Key。
  - 复用现有重试、模型回退、多模态降级与 Token 统计。
- 审计：
  - `AIOpsModelInvocation` 新增 `purpose=modeling`，记录提供商、模型、耗时、Token、费用与状态。
  - EventWall 写入 `module=aiops, action=modeling_chat` 的成功/失败记录。
- AI 面板在代理模式隐藏本机 Key/Base/Model 设置，契约随设计器发布到 `/dc-designer-app/api/agent/openapi.json`。
- 独立工作台仍可使用本机直连/本机代理，不经过平台模型代理。

## 已知限制

- 本版未跑完整后端测试套件；不能用专项测试替代全量结论。
- AI 建模的模型质量取决于默认提供商的模型能力与画布描述；审计只记录调用元数据，不保存完整提示词与模型回复正文。
- 平台项目库与独立工作台仍是两种数据归属；跨模式使用需通过 JSON 导入/导出。
