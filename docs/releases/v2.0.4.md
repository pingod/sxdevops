# SxDevOps v2.0.4 版本更新说明

本文记录 `v2.0.4` 的功能变更与升级要求，可用于 GitHub Release。发行源码以 `refs/tags/v2.0.4` 为准。

v2.0.4 的主题是**告警通知闭环与部署交付**：补齐多云短信/语音直连、通知渠道模板与说明、Ansible 控制端、国内源构建，并把 Kubernetes 清单扩展到与 Compose 一致的完整服务。

## 功能变更

### 告警中心

- 通知渠道支持内置模板与“目标说明”面板：按短信、语音、邮件、钉钉、飞书、企微、WPS 分别给出目标、必填配置、模板规则、变量和示例。
- 钉钉支持加签、@手机号和@所有人；飞书支持签名密钥。
- 新增 WPS 协作群机器人渠道，按 Markdown 发送并支持 @用户。
- 短信、语音支持阿里云、腾讯云、华为云直连；保留 Webhook 网关模式。
- 渠道“测试”改为固定样例告警，新增 dry-run 预览；模板支持 `{label.xxx}`、`{annotation.xxx}`、`{level_display}`、`{status_display}`。

### 可观测性与运维

- 日志数据源原生支持 VictoriaLogs。
- 新增巡检中心：主机/K8s/中间件巡检、AI 解读与隐患闭环。
- 数据中心新增“机柜布设”子菜单与单柜编辑器。
- 修复网络告警在 PostgreSQL 上因主机名 `inet` 查询失败、卡片按钮重复操作、内置 MCP 鉴权同步 500 等问题。

### 部署与构建

- 发行镜像内置 `ansible-core` 2.21、`sshpass` 和 `openssh-client`，主机任务可直接选择 Ansible。
- 构建全部使用国内源：基础镜像 daocloud、apt/PyPI 阿里云、npm/pnpm npmmirror；kubectl 改用 Debian `kubectl-client`。
- 镜像裁剪：删除未使用运行时文件并对 site-packages `.so` 执行 strip，Web 镜像约 516MB。
- Kubernetes 清单扩展到 8 个应用 Deployment：Web、CMDB、AIOps worker、巡检、网络轮询、告警升级、可观测性调度器、规划引擎；新增 `planning-projects` PVC 和 `planning-engine` Service。

## 升级要求

1. 重建应用镜像，Web、调度器、worker 必须使用同一镜像。
2. 执行数据库迁移：

   | 迁移 | 说明 |
   | --- | --- |
   | `ops.0065_inspection_models` | 巡检中心模型 |
   | `ops.0066_logdatasource_victorialogs` | 日志数据源支持 VictoriaLogs |
   | `ops.0067_alert_channel_wps` | 通知渠道新增 WPS 协作 |
   | `aiops.0032_inspection_capability` | 巡检能力目录 |
   | `datacenter.0003_rackproject_rackprojectsnapshot` | 机柜布设方案与版本快照 |

3. Kubernetes 使用 `k8s/deploy.py` 升级；脚本现在会同时缩容/启动 8 个应用服务，并执行一次独立迁移 Job。不要直接 `kubectl delete -f`。
4. 继续使用原有 `CMDB_PASSWORD_ENCRYPTION_KEY`；更换密钥会导致已有 SSH/SQL/云厂商/模型/MCP 凭据无法解密。
5. `kubectl` 由 Debian 包提供 1.32.3，连接更高版本集群时可能出现版本偏差提示，常规 API 操作不受影响。

## 验证

- 告警相关测试 29 个通过；新增厂商签名、模板渲染、渠道说明等覆盖。
- `ops.test_host_tasks` 38 个测试通过；镜像内 `ansible`、`ansible-playbook`、`sshpass`、`ssh`、`kubectl` 均已验证。
- `k8s/test_deploy.py` 16 个测试通过；清单包含 20 个 Kubernetes 资源。
- 本地 Compose 全部 8 个应用容器重建完成，`/healthz` 正常。
- CI 修复了 PostgreSQL 测试库销毁时后台线程残留连接导致的失败；以本版本提交后的 CI 结果为准。

## 已知限制

- Kubernetes 清单不包含 Ingress，需按环境自行配置 HTTPS/WebSocket 入口。
- 主机任务仍依赖目标主机可 SSH 登录；Ansible 密码认证需要控制端 `sshpass`，镜像已内置。
- 无重试/退避的云短信、语音发送；厂商限流错误会写入通知记录。
